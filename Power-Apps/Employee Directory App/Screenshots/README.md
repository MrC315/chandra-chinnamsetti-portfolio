# Employee Directory App - Screenshots

This folder contains screenshots of the **Employee Directory Power Apps application**, showcasing the user interface, core features, and end-to-end employee request workflow.

## Screens Included

### 🏠 Home Screen
Displays the Employee Directory landing page with employee search, navigation, and quick access to employee management functions.

### 👤 Employee Details
Shows employee profile information including:
- Employee ID
- Email
- Phone Number
- Job Title
- Department
- Location
- Hire Date
- Employment Status

### ✏️ Edit Employee
Demonstrates the employee maintenance form used to update employee information with validation and user-friendly controls.

### ➕ Add Employee
Illustrates the employee onboarding form for creating new employee records in Dataverse.

### 📝 Submit Employee Request
Displays the employee request submission form where users can:
- Submit business requests
- Select request type
- Choose an approver
- Provide request details
- Initiate an approval workflow

### ⚙️ Power Automate Approval Workflow
Shows the automated approval process including:
- Dataverse trigger
- Manager approval
- Approval/Reject branching
- Status updates
- Email notifications

## Technologies Used
